# motopark-
MotoPark 🏍️
MotoPark es una aplicación web gratuita diseñada para ayudar a los motoristas a encontrar aparcamientos específicos para motos en cualquier ciudad.

🚀 Funcionalidades
Búsqueda por dirección: Localiza aparcamientos en base a tu destino.
Radios de búsqueda: Filtra resultados por 300m, 500m o 1km.
Distancia real: Calcula la distancia real por calles mediante OSRM.
Navegación: Enlaces directos a Google Maps para llegar a tu destino.
Responsive: Optimizado para usar desde el móvil mientras estás en ruta.
🛠️ Tecnologías utilizadas
HTML5, CSS3 y JavaScript (Vanilla).
Leaflet.js: Para la renderización de mapas interactivos.
OpenStreetMap & Overpass API: Para la obtención de datos de aparcamientos.
Nominatim API: Para geocodificación de direcciones.
OSRM (Open Source Routing Machine): Para el cálculo de distancias reales.
